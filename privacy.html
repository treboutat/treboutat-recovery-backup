Privacy policy

Effective October 7, 2026.

Purpose and data accessed

Treboutat Recovery Backup is a private utility operated by its owner. Google Drive access is used to create, list, read, update and, when the owner explicitly authorizes retention cleanup, delete files created or explicitly used with this application. It does not request access to unrelated existing Drive files, Gmail, contacts, calendars or advertising data.

Use and storage

Selected local files and application state are encrypted with restic before upload. Google Drive stores the resulting encrypted repository and its file metadata. The encryption recovery key is held separately in the owner’s password manager. OAuth credentials and operational receipts are stored locally with restricted filesystem permissions. Authentication tokens enable the authorized backup and restore operations.

Sharing and limited use

Google processes authentication and Drive storage requests. The owner’s password manager stores the recovery key. The utility does not sell Google user data, use it for advertising or transfer it for AI model training. Data access and use are limited to providing the owner’s backup and recovery functions. No other user can sign up through this page.

Control and retention

The owner selects backup coverage and retention. No automatic backup deletion policy is enabled at initial setup. The owner can revoke application access in Google Account settings. Revocation stops future authorized requests; it does not itself erase files already stored in Drive. Repository deletion or retention cleanup requires a separate owner instruction.

This page and contact

This page has no analytics, forms or application cookies. The hosting provider may process ordinary web-request information under its own policies. For questions, use the support address shown on the application’s Google consent screen. This policy will be updated if the utility’s data practices change.
